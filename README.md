# YWU Performance Mod 

## 1. Install BepInEx

1. Open Steam.
2. Right-click **How To Fish** → **Properties** → **Installed Files** → **Browse**.
3. Download **BepInEx 5.4.23.5 x64**.
4. Extract the BepInEx files directly into the **How To Fish** root folder. (the one with the .exe in it)
5. Launch the game once, then close it.

BepInEx should create a `BepInEx` folder with a `plugins` folder inside.

## 2. Install YWU Performance Mod

Open:

```text
How To Fish\BepInEx\plugins
```

Drag and drop:

```text
YWUperfmod.dll
```

into the `plugins` folder.

Your final setup should look like:

```text
How To Fish/
└── BepInEx/
    └── plugins/
        └── YWUperfmod.dll
```

## 3. Launch

Start **How To Fish** normally.

BepInEx should automatically load `YWUperfmod.dll`.

**Done!**
